# 使用指南（V2 产品版 · product 分支）

> 面向使用者的手把手操作指南。当前系统以 **v2 模型**（CIC-IDS2017，HistGradientBoosting）运行，支持 CSV 与 PCAP 上传、告警中心与处置建议。

---

## 1. 启动系统（每次开机后需做）

| 步骤 | 命令 | 说明 |
|---|---|---|
| ① 启动数据库 | 管理员 PowerShell：`Start-Service MySQL80` | 重启电脑后 MySQL 默认停止，必须先启动 |
| ② 启动后端 | `cd d:\my-project\ml_network_anomaly_detection\backend`<br>`..\venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000` | 窗口保持开着；看到 `Application startup complete` 即成功 |
| ③ 启动前端 | 新开终端：`cd d:\my-project\ml_network_anomaly_detection\frontend`<br>`npm run dev` | 窗口保持开着；默认地址 http://localhost:5173 |
| ④ 打开页面 | 浏览器访问 **http://localhost:5173** | 用 Vite 代理地址，不要直接开 8000 |

> 验证：后端健康检查 http://127.0.0.1:8000/health 返回 `{"status":"ok"}` 即一切正常。

---

## 2. 注册与登录

1. 打开 http://localhost:5173 → 自动跳转登录页
2. 点击「注册」，用户名 3~50 字符、密码 6~64 字符
3. 注册成功后登录，进入「上传检测」页

---

## 3. 上传检测（三种文件都能传）

| 文件类型 | 要求 | 说明 |
|---|---|---|
| NSL-KDD CSV | 41 列（带表头）或 42 列（无表头） | 项目格式，v1/v2 模式均可 |
| CIC-IDS2017 CSV | 78 特征列 + Label | v2 原生格式，表头自动识别 |
| PCAP 原始抓包 | ≤50MB | 服务端解析五元组双向流并提取流特征 |

- 单文件 ≤ **50MB**，超出会被拒绝
- **演示样本**（推荐第一次用这个）：
  `d:\my-project\ml_network_anomaly_detection\backend\ml\data\cicids\demo_sample_500.csv`
  —— 500 行（200 正常 + 300 DoS slowloris 攻击），上传后能看到攻击命中和告警
- 拖入文件 → 点击「开始检测」→ 立即返回任务 ID，后台异步检测

---

## 4. 查看结果

1. 顶部菜单「任务列表」→ 状态自动从「排队中」变「检测中」再变「完成」（每 2 秒轮询）
2. 点击「查看报告」→ 三张图：
   - 检测结果占比饼图（Normal vs Attack）
   - 平均置信度对比柱图
   - 置信度分布直方图
3. 500 行样本参考预期：约 300 行判 Attack、200 行判 Normal，端到端约 2 秒

---

## 5. 告警中心（V2 核心新能力）

**触发条件**：模型判定 Attack **且置信度 ≥ 0.90** 的行，按攻击源去重后生成告警。

1. 顶部菜单「告警中心」，红点数字 = 待处置告警数（每 15 秒自动刷新）
2. 告警按置信度降序排列，每条包含：
   - **攻击源**：IP 地址（或行引用）
   - **置信度**：进度条显示
   - **处置建议命令**：如
     `New-NetFirewallRule -DisplayName "NADS block 172.16.1.50" -Direction Inbound -RemoteAddress 172.16.1.50 -Action Block`
3. **处置方式**（二选一）：
   - 「复制」命令 → 自己粘贴到**管理员 PowerShell** 审核后执行（系统绝不自动执行）
   - 「确认」（ack）：已处置完毕；「忽略」（dismiss）：误报
4. 注意：CSV 无 IP 列时攻击源显示 `row-N`（行引用），PCAP 上传的告警才是真实 IP

## 6. 切换模型（可选）

编辑 `backend/.env` 后**重启后端**生效：

| 配置项 | 值 | 效果 |
|---|---|---|
| `MODEL_VERSION` | `v2`（当前） | CIC-IDS2017 模型，现代攻击面 |
| `MODEL_VERSION` | `v1` | NSL-KDD 项目模型（设计文档口径） |

## 7. 常见问题

| 现象 | 原因与解决 |
|---|---|
| 页面弹「无法连接后端服务」 | 后端 uvicorn 没启动，或 MySQL80 停了导致接口 500；按第 1 节顺序检查 |
| 上传被拒 400「无法连接数据库」 | MySQL80 没启动 → 管理员 PowerShell 执行 `Start-Service MySQL80` |
| 上传被拒 400 列不匹配 | CSV 列与模型契约不符，报错信息精确到缺哪列/多哪列 |
| 登录失效跳回登录页 | JWT 默认 60 分钟过期，重新登录即可 |
| 告警中心是空的 | 上传的样本没有高置信（≥0.90）Attack 命中；用第 3 节演示样本试试 |
| 传 PCAP 后行数很少 | 正常：一个流 = 一行（不是一包一行） |

## 8. 边界与安全声明

- 系统定位为**旁路事后分析 + 高置信告警初筛**，不承诺实时拦截
- 处置命令**只生成不执行**，自动阻断在本项目中永久禁止
- v2 模型指标为同分布口径（Acc=0.9987 / Recall=0.9996），真实网络效果未验证
- 仅用于公开数据集分析与教学演示，不对任何未授权网络发起主动探测
